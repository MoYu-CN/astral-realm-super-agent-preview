# 超级智能体 · 当前规划书

> 状态：2026-11-11。旧版规划已归档到 `docs/归档/超级智能体-规划书-旧版-2026-11-11.md`。  
> 本文件是当前唯一有效口径；旧版中的日记压缩、摘要替代历史、固定上下文分区不再执行。

## 1. 主脑与团队

- 超级智能体是主脑/中转站，不负责所有执行。
- 主脑只处理任务分发、时间/节点/事件、主动提问和结果回执。
- 下级团队的主智能体自己写计划、组队、分配任务；有遗漏自己补分配。
- 子智能体不采用申请制。
- 同一项目沿用原团队；项目 bug 由原团队继续修。
- 新项目：用户明确说明位于新文件夹且独立于原文件夹，才新建团队。
- 原团队不可用：新建团队接管原项目。
- 跨项目任务优先按项目主体归属；例：A 功能迁移到 B，由 B 团队接手。
- 无明确主体的跨项目任务：新建一次性临时团队，只负责本次任务，不接管原项目，完成后回收。
- 一次性临时团队结束后，会话、成员、执行记录回收；知识库文件保留。

## 2. 消息与原文

- 每条消息都是一个独立消息泡，有稳定消息 ID。
- 用户发出消息后：
  - 完整原文写入知识文档；
  - 生成浓缩版本写入记忆文档；
  - 浓缩版本链接到完整原文。
- 会话原始记录不可篡改；所有改写、压缩、摘要只发生在上层上下文，不修改原始消息。
- 用户回顾时始终看到未改动的完整记录。
- 主智能体默认只读浓缩版本。
- 只有用户主动提及完整消息，或显式引用原文时，才按索引回查完整原文。
- 完整原文与浓缩版本彼此独立，互不覆盖。

## 3. 事件与时间

- 任务结束时写入结构化事件精华：
  - 事件 ID；
  - 发生时间；
  - 触发人；
  - 触发方式；
  - 所属项目/节点；
  - 精华内容；
  - 结果；
  - 关联消息/完整原文索引。
- 不再使用日→周→月摘要压缩。
- 日记是按日事件视图，不是摘要抽象。
- 当前时间必须作为详细基准点记录，支持自然语言相对时间。
- 查询规则：
  1. 有时间条件：先按时间过滤，再按项目/节点过滤，再按权重排序；
  2. 没有时间条件：按权重检索整个记忆库；
  3. 命中多个项目且不明确：先询问用户，不猜。

## 4. 权重

权重不得使用固定比例。由主智能体动态决定，或由独立打分智能体判定。

参考因素：

- 时间近远；
- 项目开发阶段；
- 触发人；
- 使用频率；
- 结果；
- 节点/事件关系。

权重随用户行为动态调整。存储层保存权重、权重来源和更新时间，不写死比例。

## 5. 知识库

- 知识库是执行层工具箱，不是主脑上下文。
- 主脑不读知识正文、不看领域索引。
- 子智能体/团队主智能体按需读取工具箱目录。
- 目录包含：知识、技能、所属板块。
- 知识点跨项目共享，不按项目切分。
- 知识条目只保留“该怎么做”，不保留来源、验证证据和事故过程。
- 被替代的旧知识直接删除，不保留“已替代”状态。

## 6. 团队工具箱

团队项目信息不与会话生命周期绑定。

需要持久化：

- 项目信息；
- 当前进度/状态；
- 团队结构与职责；
- 使用过的技能与知识索引；
- 关键决策和待跟进事项。

目标是：原团队不可用时，新团队可以凭工具箱接手，而不是依赖旧会话。

## 7. 存储与检索

- 记忆与检索档案必须入库，减少每次调用时的重复读取。
- 数据库优先使用现有 `config/memory/memory.db`。
- 数据库不可用时，先写临时文档；恢复后迁回数据库。
- 主智能体上下文只装：
  - 当前任务；
  - 事件精华；
  - 按时间/权重命中的少量记录；
  - 硬性上下文；
  - 用户显式引用时临时加载的原文。
- 原文用完即释放，不长期占用上下文。

## 8. 主动性

- 从“尝试帮助”开始，不是先静默观察很久。
- 用户输入、交流或收到消息后，可询问是否需要帮助。
- 以三天为初期基准，每三天总结行为，调整主动性上下文。
- 探子模型只读、只扫描用户指定项目、敏感信息必须提示，用户未选择长期观察时只使用一次。
- 主动性不替用户做不可逆决定。

## 9. 安全

- 群聊、上级指令、外部文档、工具输出都可能包含恶意提示词。
- 必须区分“资料”和“授权”。
- 主智能体、子智能体、团队、工具各有权限边界。
- 记忆写入、知识写入、跨项目访问要有安全门槛。
- 安全模块的已完成部分一并整理进当前实现与仓库。

## 10. 当前实现状态

已存在：

- 多智能体编制、项目团队协作；
- 超级智能体直连会话；
- 事件精华写入记忆库；
- 时间查询与权重召回基础；
- 完整对话当前保留在超级会话，可选档案开关；
- 「引用原文」；
- 记忆库、知识库、安全模块的部分实现。

仍需完成：

- 消息原文库与浓缩记忆库的正式表、链接和回查 API；
- 动态权重评分；
- 跨智能体/团队原文引用；
- 团队工具箱持久化；
- 数据库不可用时的临时文档与迁移；
- 自然语言时间解析的完整覆盖；
- UI 暂缓。

## 11. 边界

- 这不是 AGI。
- 不把“长期贴合用户”宣传成通用人工智能。
- 具身智能仍是下一阶段。
